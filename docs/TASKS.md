# 任务拆解（分阶段，每阶段一次 commit）

> 原则：每完成一个阶段就 commit 一次，中文 commit message；阶段内任务你逐条审核后我再动手，不一口气全建完。
>
> 开发方式：**页面骨架先行 + 每阶段前后端一起交付**（垂直切片），每做完一个阶段都能在浏览器里点着测。

---

- [ ] `git init` + 建目录骨架（`pom.xml`、Spring Boot 启动类、分层包结构）
- [ ] `docker-compose.yml`（MySQL 8）
- [ ] 数据库建表脚本（`schema.sql`：user / file / upload_session / file_chunk）
- [ ] 配置 MyBatis + 数据源 + Thymeleaf
- [ ] 页面骨架：登录页、注册页、主界面文件列表页（假数据占位）+ 页面导航

**可测点**：`docker compose up` 起 MySQL，应用启动连库；三个页面能点开、能互相跳转。

## 阶段 5：秒传（MD5 去重）
- [ ] 上传前客户端算 MD5

**可测点**：相同文件第二次上传秒回；删除后引用计数正确。

## 已确认的默认项（来自需求文档 §8）
- 删除策略：物理删除，暂不做回收站
- 图片缩略图：前端 `<img>` 原生缩略，后端不生成缩略图
- 管理员角色：暂不做
- 大文件阈值：单文件上限 5GB；>20MB 走分片，单片 5MB
- 秒传去重范围：全局去重 + 引用计数
- ORM：MyBatis
- 配额扣减：先乐观锁（version 重试），压测冲突高再换悲观锁
