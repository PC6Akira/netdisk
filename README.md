# netdisk —— 多人在线网页版网盘系统

面试深挖用项目，对齐简历：多线程架构 + 千人在线 + 用户体系 + 文件管理 + 在线预览。

## 技术栈

Java 21 · Spring Boot 3 · MyBatis · MySQL 8 · Thymeleaf · JWT · JMeter

## 文档

- [需求文档](docs/requirements.md)

## 快速启动

1. 启动 MySQL：`docker compose up -d`
2. 启动应用：`mvn spring-boot:run`
3. 访问 <http://localhost:8080>
